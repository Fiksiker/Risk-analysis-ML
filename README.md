# Кредитный риск анализ и прогнозирование

## Описание проекта

Проект представляет собой анализ данных по кредитному скорингу и построение моделей для прогнозирования одобрения кредита. Датасет содержит 5000 записей клиентов с 10 признаками, включая возраст, доход, сумму кредита, кредитный рейтинг и другие социально демографические характеристики.

## Проделанная работа

### Исследовательский анализ данных

Проведен первичный анализ датасета. Изучена структура данных, типы признаков, выявлены пропуски в столбцах Income, CreditScore и Education. Построены корреляционные матрицы и визуализации зависимостей между признаками. Обнаружены отрицательные значения в Income и LoanAmount, а также сильный дисбаланс целевого признака LoanApproved.

На основе анализа сделаны выводы о важности кредитной истории и уровня дохода, а также о том, что возрастная группа 30 40 лет является наиболее надежными клиентами.

### Предобработка данных

Выполнено копирование исходных данных для безопасной трансформации. Пропуски в Income и CreditScore заполнены медианными значениями. Признак Gender преобразован в бинарный формат с кодировкой 1 для Male и 0 для Female.

Отрицательные значения в Income и LoanAmount заменены на абсолютные значения. Признак City преобразован в числовой формат через замену на средний доход по каждому городу. Признак Education удален из датасета из за большого количества пропусков.

Проведена стандартизация числовых признаков с использованием StandardScaler.

### Построение моделей

Данные разделены на обучающую и тестовую выборки в соотношении 80 на 20 со стратификацией по целевому признаку.

Обучена логистическая регрессия с учетом дисбаланса классов через параметр class_weight. Коэффициенты модели показали, что CreditScore имеет наибольшее влияние на решение о выдаче кредита с коэффициентом 1.60, за которым следует Income с коэффициентом 0.76.

Построен случайный лес с настройкой глубины деревьев и количества оценщиков. Модель показала улучшение метрик по сравнению с логистической регрессией.

Обучен классификатор XGBoost с подбором параметров включая scale_pos_weight для работы с дисбалансом классов.

### Оценка качества моделей

Для каждой модели рассчитаны матрица ошибок, точность, полнота и F1 мера. Наилучшие результаты показал случайный лес с полнотой 0.887 и F1 мерой 0.727. Проанализирована важность признаков для каждой модели. Во всех моделях CreditScore остается доминирующим фактором: в случайном лесе важность CreditScore составляет 0.627, в XGBoost - 0.400, что подтверждает доминирование этого признака в обеих моделях

## Используемые библиотеки

pandas для обработки данных, matplotlib для визуализации, scikit learn для предобработки и моделей логистической регрессии и случайного леса, xgboost для градиентного бустинга.
